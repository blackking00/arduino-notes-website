## 🚀 VS Code se GitHub Pages Deploy Karo

1. VS Code mein folder kholo
2. **Source Control** panel mein "Initialize Repository" karo
3. Commit message likho — `"Initial commit"`
4. GitHub par publish karo
5. GitHub Settings → Pages → Branch: main → Save
6. Link ready: `https://yourusername.github.io/arduino-cpp-notes`
